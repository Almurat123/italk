# Eye cards v6

Date: 2026-10-26

Nine independent concept sheets generated with the built-in image_gen tool, one call per sheet. No reference image inputs were used. Each sheet shows intended CALM, LISTEN, JOY states. All nine retain a circular colored body and visible eyes, following the user's correction that eyes are essential to the character.

## Visual review

- Inspected all nine outputs. Each contains three eye-bearing circular characters and three state labels.
- These are static concept images, not implemented motion. Emotional readability and small-avatar legibility have not been user-tested.
- 02, 05, 06 and 09 most closely preserve minimal filled eye silhouettes. 04 makes gaze direction explicit through pupils.
- The model added eye highlights to 01, 03, 07 and 08 despite the prompt requesting flat simplicity. 03 also diverges from the specified half-moon eyes. Titles record intended explorations rather than exact compliance.
- Subtle raster shading remains despite the uniform-fill direction. Any chosen concept should be recreated as genuinely flat native shapes for the app.
- Several happy poses converge on similar closed smile-eyes; differentiation is strongest in calm and listening poses.
- No app source, runtime, project configuration or Claude-owned files were changed. No app build was necessary for this image-only exploration.

```text
Use case: stylized-concept.
Asset type: iTalk voice companion expression exploration sheet.
Create one beautifully composed landscape 1536x1024 concept sheet showing EXACTLY THREE large instances of the SAME minimal character, evenly spaced in a horizontal row. Visual language: one simple solid-color circular body, two expressive eyes INSIDE the circle, extremely clean flat vector-like graphic design, sharp smooth edges. Default body is a true circle. Typography: place small elegant off-white labels under the three bodies: "CALM", "LISTEN", "JOY". One small sheet number in upper left only. No other words. Generous whitespace, large readable eyes and bodies, professional character design exploration, not a polished app screenshot.
Specific concept:
Sheet number 01. Bright periwinkle-blue body #7275F5, near-black eyes. Eye family: two upright plump soft kidney-bean silhouettes, organically curved, distinctly NOT parallel diagonal capsule strokes. Calm: softly open bean eyes with a tiny natural height mismatch. Listen: one opens taller and the other compresses subtly, both glance to upper left. Joy: both beans become thick happy upward crescent arches, still clearly two eyes.
```
