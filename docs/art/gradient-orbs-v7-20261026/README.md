# Gradient orb cards v7

Date: 2026-10-26

Ten separate image-generation calls using the built-in image_gen tool. No input reference images were provided. The request was to explore a GPT-like soft gradient orb direction as an alternative to the preceding eye-based concepts. This set explores the orb field itself without eyes.

## Visual inspection

- All ten outputs were visually inspected: one round orb per card, gradient structures inside the silhouette, light background, no face, external glow ring or heavy border.
- These are static concepts. No animation, speech synchronization, native rendering or on-device appearance has been implemented or tested in this round.
- 01, 03 and 08 are the lightest blue-white treatments; 02 and 07 use stronger dark blue anchors. 04, 05, 06 and 10 broaden the palette.
- 07 retains more internal cloud texture than the requested clean smooth field. 09 and 10 read more as overlapping smooth bands than diffuse clouds. The selected design would need motion studies before judging its speaking/listening behavior.
- Concept numbers are generated labels, not app UI.
- App source, project configuration, runtime and Claude-owned files were not changed. All files added in this round are in this versioned art directory.

## Complete prompt set

### 01 晴空云流

```text
Use case: stylized-concept.
Asset type: one standalone concept card for an iTalk voice AI orb.
Primary request: explore the soft luminous fluid-gradient voice-orb visual language associated with contemporary conversational AI. Make an original composition, not an official product screenshot or logo reproduction.
Composition: exactly ONE large perfectly circular orb centered in a square 1024x1024 image, diameter about 610px, generous whitespace around it. Flat warm white background #FAFAF8, absolutely no background gradient. All color, light and movement-like forms are confined WITHIN the circular silhouette. Clean antialiased edge, no heavy outline, no ring, no drop shadow, no halo outside it. The circle is an abstract digital field rather than a physical glass marble.
Medium: refined very smooth volumetric color blending with broad soft organic gradients and a restrained number of flowing shapes. Feels alive, calm, tender and breathable, like a still frame of continuously moving liquid light. Clear hierarchy, quiet composition, no dense complexity.
Avoid: eyes, face, mouth, creature anatomy, accessories, interface controls, microphones, wave bars, sparkle symbols, cosmic galaxies, stars, particles, noise, grain, material textures, sharp chrome reflections, glass shell, realistic planet, tiny intricate tendrils, rainbow bands, tangled ribbons, donut holes, branding, watermarks.
Typography: only the specified two-digit concept number, small neutral-gray text near upper left of the canvas; no other text.

Specific variation:
Number 01. Palette: clear sky-blue, soft cornflower blue and milky white. Orb interior: one broad white cloud-like mass gently rising from the lower left, wrapping a clean blue upper field, with barely visible soft swirling transitions. Feels airy, open and friendly; the simplest and lightest concept. No thin strands or marbling.
```
